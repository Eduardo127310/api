# API de Receitas — Projeto 2 (Programação Web Back-End)

API JSON para login, cadastro e consulta de receitas, feita com **Python + Flask** e **MySQL**, seguindo o padrão **MVC** e o padrão **REST** nas rotas.

Continuação do Projeto 1 (mesma temática: receitas).


---

## Funcionalidades

- Login e logout de usuários
- Cadastro de receitas (somente para usuários logados)
- Busca de receitas por nome ou ingrediente, com paginação
- Busca de usuários por nome
- Página de cada autor com as receitas dele
- Front-end simples para usar todas as rotas

## Tecnologias

- Python 3
- Flask
- MySQL (via `mysql-connector-python`)
- HTML + JavaScript (front-end simples)
